# Adrobot ТЗ

Keitaro — рекламный трекер, с помощью которого команда отслеживает прибыльность объявлений. Трекер перенаправляет посетителей по настроенным правилам и показывает статистику редиректов. На первой странице оригинального ТЗ показан пример кампании.

## 1. Создание кампаний

Форма принимает название кампании, геокод страны и ID оффера Keitaro. Созданная кампания должна иметь настроенные домен, группу и источник. Эти параметры доступны через API.

В кампании должно быть два потока.

1. Первый поток отправляет посетителей из указанной страны на Google.
2. Второй поток отправляет остальных посетителей на выбранный оффер.

На второй странице оригинального ТЗ показан пример формы `New campaign` с полями `Name`, `Geo`, `Offer` и кнопкой `Create`. Для поля `Offer` показан поиск по офферам с автодополнением. На той же странице есть скриншот настройки домена, группы и источника.

## 2. Редактирование существующей кампании

Редактор должен уметь добавлять и удалять офферы в кампании. Нужно воспроизвести логику из видео. Оформление интерфейса можно выбрать самостоятельно. Кнопки должны работать, а цифры — отображаться верно. [Видео «keitaro wrapper - test»](https://youtu.be/jNloscEWCjA)

### Поведение редактора из видео

- `Fetch Streams` загружает все потоки кампании. Для потока с офферами показываются офферы и их доли. В видео поток редиректа показан только названием. В редакторе проекта потоки редиректа скрыты.
- Оффер для добавления можно найти по ID в каталоге Keitaro. `Add` добавляет его в черновик и сразу пересчитывает доли в интерфейсе. Поток с неопубликованными изменениями выделяется жёлтым. Изменения попадают в Keitaro после `Push`. `Cancel` отменяет неопубликованные изменения. Добавленные в черновике привязки исчезают, сами офферы остаются в каталоге, а поток снова отображается белым.
- `Remove` помечает оффер серым и показывает долю `0%` в редакторе. После `Push` оффер исчезает из потока в Keitaro, а в редакторе остаётся в архиве со статусом `removed`. `Bring back` возвращает оффер в черновик. Чтобы привязка вернулась в Keitaro, нужно снова нажать `Push`.
- При повторном `Fetch Streams` ранее известные редактору офферы, которых больше нет в Keitaro, тоже переходят в `removed`. Их можно восстановить через `Bring back` и `Push`.
- Пользователь может закрепить текущую долю оффера. При добавлении, удалении и восстановлении офферов закреплённые доли сохраняются. Остаток от `100%` распределяется поровну между активными офферами без закреплённой доли. Например, четыре активных оффера без закрепления получают по `25%`.

### Как сдавать тестовое

Проект должен быть написан на FastApi + SQLAlchemy. Фронт - можно сделать любой, хоть React, хоть HTML-ки с кусками jquery. 

Сдавать работу в виде ссылки на гитхабе с понятным README для миграций и запуска. Использование агентов типа Cursor/Windsurf категорически приветствуется.
