# Проект

FastAPI-обёртка Keitaro для создания кампаний и редактирования их офферов.

- `app/main.py` и `app/templates/` — маршруты, HTML-формы и шаблоны Jinja. Точка входа `app.main:app`.
- `app/campaigns.py` и `app/editor.py` — создание кампаний и редактирование офферов. Запросы Keitaro собраны в `app/keitaro.py`.
- `app/database.py` и `migrations/001_initial.sql` — подключение к SQLite и схема состояния редактора. Миграцию запускает `utils/migrate.py`.
- `pyproject.toml` и `uv.lock` — зависимости, настройки Ruff и зафиксированные версии пакетов.
- `README.md` — настройка, запуск и тесты. `docs/tz.md` — требования задания, включая поведение редактора из видео.
- `docs/kt-emulator.md` — контракт учебного стенда и примеры запросов.

## Правила работы

- Используй Python 3.13 и `uv`. Согласовывай новые зависимости, добавляй их через `uv add` и обновляй `uv.lock` вместе с `pyproject.toml`.
- Держи HTTP-вызовы Keitaro в отдельном клиенте, а логику кампаний и офферов вне обработчиков FastAPI. Для клиента используй контракт стенда и официальные поля Admin API.
- Бери ключ Keitaro из окружения. Адрес стенда задан в `app/keitaro.py`. Исключай `Api-Key` из логов и файлов репозитория.
- Храни черновики, архив и закреплённые доли редактора в SQLite. Публикуй изменения только по кнопке «Опубликовать». `PUT /streams/{id}` заменяет весь список `offers`, поэтому передавай все привязанные офферы и исключай удалённые. [Поведение редактора](docs/tz.md#поведение-редактора-из-видео)
- Обычные тесты подменяют Keitaro и работают без ключа и сети. Тесты с реальным стендом храни в `tests/test_keitaro_integration.py`, помечай `pytest.mark.integration` и запускай отдельно через `uv run --env-file .env pytest -m integration`. Удаляй созданные ими кампании.
- Перед завершением запусти `uv run ruff check .` и `uv run ruff format --check .`.
